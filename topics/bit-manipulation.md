# 位运算

## 常用运算

```cpp
a & b   // 按位与：两位都是 1，结果才是 1
a | b   // 按位或：至少一位是 1，结果就是 1
a ^ b   // 按位异或：两位不同，结果就是 1
~a      // 按位取反：0 变 1，1 变 0
1 << k  // 只有第 k 位为 1
```

## 判断第 k 位

```cpp
if (value & (1 << k)) {
    // value 的第 k 位是 1
}
```

## 把第 k 位设为 1

```cpp
value |= (1 << k);
```

## 构造低 bitLength 位全为 1 的掩码

```cpp
long long mask = (1LL << bitLength) - 1;
```

例如 `bitLength = 4` 时，`mask` 的二进制是 `1111`。

## 所有元素按位与

```cpp
int allAnd = (1 << 30) - 1;

for (int value : nums) {
    allAnd &= value;
}
```

结果中的某一位为 `1`，表示所有元素的这一位都是 `1`。

## 位运算题的常见思路

当操作只包含与、或、异或时，可以尝试把整数拆成多个二进制位，每一位独立分析。
