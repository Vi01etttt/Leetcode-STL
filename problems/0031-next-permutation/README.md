# 0031. Next Permutation

难度：Medium  
专题：Array, Two Pointers  
链接：https://leetcode.com/problems/next-permutation/

## 题意

给定一个整数数组 `nums`，要求把它原地修改成字典序中的下一个排列。

如果当前排列已经是最大排列，比如 `[3,2,1]`，则改成最小排列，也就是升序 `[1,2,3]`。

要求：

- 必须原地修改。
- 只能使用常数级额外空间。

## 核心思路

想让排列“刚好变大一点”，应该从右往左找第一个可以变大的位置。

例如：

```text
[1, 2, 7, 4, 3, 1]
```

从右往左看，`7, 4, 3, 1` 是递减的，已经是这一段能组成的最大排列。

第一个破坏递减趋势的位置是 `2`：

```text
[1, 2, 7, 4, 3, 1]
    ^
```

只要把 `2` 换成右侧刚好比它大的数，也就是 `3`，整体就能变大，并且尽量小。

交换后：

```text
[1, 3, 7, 4, 2, 1]
```

最后把右侧后缀反转成升序：

```text
[1, 3, 1, 2, 4, 7]
```

这就是下一个排列。

## 算法步骤

1. 从右往左找到第一个位置 `i`，满足 `nums[i] < nums[i + 1]`。
2. 如果找不到，说明整个数组递减，直接反转整个数组。
3. 从右往左找到第一个位置 `j`，满足 `nums[j] > nums[i]`。
4. 交换 `nums[i]` 和 `nums[j]`。
5. 反转 `i + 1` 到末尾的后缀。

## 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 易错点

- 第一步找的是 `nums[i] < nums[i + 1]`，不是 `<=`。
- 第二步从右往左找第一个大于 `nums[i]` 的数，这样才能保证“刚好更大”。
- 交换后必须反转后缀，因为原后缀是递减的，反转后才是最小的升序。
- 如果数组完全递减，直接反转整个数组。
