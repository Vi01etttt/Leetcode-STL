# 0031. Next Permutation 复盘

## 解法

标准做法是从右往左找第一个能变大的位置，然后让它变成右侧“刚好比它大”的数，再把后缀变成最小排列。

## 识别信号

- 题目要求“下一个字典序排列”。
- 要求原地修改。
- 不能生成所有排列。

这些条件通常指向 `next_permutation` 的手写过程。

## 为什么要反转后缀

从右往左找到 `i` 时，`i + 1` 到末尾一定是递减的。

递减说明这段后缀已经是最大排列。交换 `nums[i]` 后，为了让整体只变大一点点，需要让后缀变成最小排列，也就是升序。

因为后缀原本递减，所以直接 `reverse` 就能变成升序。

## 下次重写检查

- `i` 是否从 `n - 2` 开始？
- 找 `i` 的条件是否是 `nums[i] >= nums[i + 1]`？
- 找 `j` 时是否从最右边开始？
- 最后是否无论如何都反转了后缀？
