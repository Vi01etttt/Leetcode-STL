# 3. 无重复字符的最长子串

难度：中等  
专题：字符串 / 哈希集合 / 滑动窗口

## 思路

使用 `[left, right]` 表示当前窗口，并保证窗口内没有重复字符。

右指针每次加入一个新字符：

1. 如果 `s[right]` 已经在窗口中，就不断删除最左边的字符，并让 `left` 右移。
2. 直到 `s[right]` 不再重复，再将其加入窗口。
3. 使用 `right - left + 1` 计算当前窗口长度并更新答案。

## 为什么使用 while

遇到重复字符时，可能需要从左边删除多个字符才能消除重复。

例如窗口是 `abc`，下一个字符是 `b`：

```text
abc + b
删除 a 后：bc 中仍然有 b
继续删除 b 后：c 中没有 b
加入新的 b：cb
```

因此这里必须使用 `while`，不能只删除一次。

## 复杂度

- 时间复杂度：平均 `O(n)`
- 空间复杂度：`O(min(n, 字符集大小))`

虽然代码里有嵌套的 `while`，但每个字符最多进入集合一次、离开集合一次，因此总操作次数是线性的。

## 原代码的问题

- `while (s[i])` 不能安全判断字符串是否结束；应使用 `i < s.size()`。
- `now = k - j` 中通常有 `k < j`，会得到负数。
- `j = k` 会让右指针向左倒退，破坏滑动窗口的单向移动。
- 从 `0` 检查到 `j - 1` 会把当前窗口左边、已经失效的字符也算进去。
- `string n` 没有被使用。
- `i`、`j` 和 `k` 的含义不固定，容易出现死循环或越界。
