# 0001. Two Sum

难度：Easy  
专题：Array, Hash Table  
链接：https://leetcode.com/problems/two-sum/

## 题意

给定整数数组 `nums` 和目标值 `target`，返回两个数的下标，使得它们的和等于 `target`。

题目保证每组输入只对应一个答案，并且同一个元素不能使用两次。

## 解法一：暴力枚举

最直接的想法是枚举所有不同的下标组合 `(i, j)`，检查 `nums[i] + nums[j]` 是否等于 `target`。

代码：[solution_bruteforce.cpp](./solution_bruteforce.cpp)

### 算法步骤

1. 外层循环枚举第一个下标 `i`。
2. 内层循环从 `i + 1` 开始枚举第二个下标 `j`。
3. 如果两个数之和等于 `target`，返回 `{i, j}`。

### 复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(1)`

### 适合记录的点

这个解法非常适合作为一刷版本：思路简单，不容易写错，可以帮助先确认题意。

面试中如果先想到暴力法，可以先说出来，再继续优化到哈希表。

## 解法二：哈希表

用哈希表保存已经看过的数字及其下标。

遍历当前数字 `x` 时，检查 `target - x` 是否已经出现过：

- 如果出现过，直接返回两个下标。
- 如果没出现，把当前数字和下标存入哈希表。

关键点是先查再存，避免同一个元素被使用两次。

代码：[solution.py](./solution.py)

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 易错点

- 不能用同一个元素两次。
- 有重复数字时，哈希表里要存下标，而不是只存数字。
- C++ 里如果题目保证一定有答案，最后的 `return` 只是为了通过编译；更推荐返回空数组 `{}`，不要返回可能误导的 `{0, 0}`。

## 复盘

- 一刷：暴力枚举，确认题意和边界。
- 二刷：哈希表查补数，练习从 `O(n^2)` 优化到 `O(n)`。
