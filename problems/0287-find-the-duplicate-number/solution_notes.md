# 0287. Find the Duplicate Number 复盘

## 解法对比

### 排序

排序后重复数字一定相邻，所以检查相邻元素即可。

- 优点：直观，容易想到。
- 缺点：修改了原数组，不满足题目要求。

### 快慢指针

利用 `nums[i]` 指向下一个位置，把数组转换成链表判环问题。

- 优点：`O(n)` 时间，`O(1)` 空间，不修改数组。
- 缺点：第一次理解比较绕，需要记住“重复数字是环入口”。

## 识别信号

- 数组长度是 `n + 1`。
- 数字范围是 `[1, n]`。
- 不能修改数组。
- 要求 `O(1)` 额外空间。

这些条件组合在一起，通常暗示可以把数组下标和值看成一条链。
