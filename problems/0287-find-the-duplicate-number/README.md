# 0287. Find the Duplicate Number

难度：Medium  
专题：Array, Two Pointers, Binary Search  
链接：https://leetcode.com/problems/find-the-duplicate-number/

## 题意

给定一个长度为 `n + 1` 的数组 `nums`，其中每个数字都在 `[1, n]` 范围内。

因为数字范围只有 `n` 个，但数组长度是 `n + 1`，所以至少存在一个重复数字。题目假设只有一个数字重复，要求返回这个重复数字。

额外要求：

- 不能修改数组 `nums`。
- 只能使用常量级 `O(1)` 额外空间。

## 解法一：排序后找相邻重复

你的一刷思路是先排序，然后检查相邻元素是否相等。

代码：[solution_sort.cpp](./solution_sort.cpp)

### 复杂度

- 时间复杂度：`O(n log n)`
- 空间复杂度：取决于排序实现，通常不算严格 `O(1)`。

### 注意

这个方法能找到答案，但不满足题目要求，因为 `sort(nums.begin(), nums.end())` 会修改原数组。

另外循环时不能写到 `i < nums.size()` 再访问 `nums[i + 1]`，否则最后一次会越界。应该写成 `i + 1 < nums.size()`。

## 解法二：快慢指针，Floyd 判环

把数组看成链表：

- 下标是当前节点。
- `nums[i]` 是下一个节点。

因为数字都在 `[1, n]`，所以从 `nums[0]` 出发一定会进入一个环。重复数字就是环的入口。

代码：[solution_floyd.cpp](./solution_floyd.cpp)

### 算法步骤

1. 慢指针每次走一步：`slow = nums[slow]`。
2. 快指针每次走两步：`fast = nums[nums[fast]]`。
3. 两指针第一次相遇后，把一个指针放回起点。
4. 两个指针都每次走一步，再次相遇的位置就是重复数字。

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 为什么符合题目要求

- 没有修改 `nums`。
- 只用了几个整数变量。

## 易错点

- 排序法会修改数组，不满足本题进阶要求。
- 排序法检查相邻元素时要避免 `nums[i + 1]` 越界。
- 快慢指针法不是在找重复下标，而是在找“环入口对应的值”。
