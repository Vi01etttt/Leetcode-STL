# 6. 密码强度检查

难度：基础  
专题：字符串 / 模拟

## 题意

依次判断每个密码的长度和字符类型，输出 `Strong`、`Medium` 或 `Weak`。

字符类型共有四种：

- 小写字母
- 大写字母
- 数字
- 特殊字符

## 思路

如果密码长度小于 8，直接输出 `Weak`。

否则遍历密码，用四个 `bool` 变量记录四种字符是否出现。由于 `bool` 在参与加法时会转换成 `0` 或 `1`，可以直接相加得到字符类型数量。

## 复杂度

- 时间复杂度：每组数据为 `O(n)`，其中 `n` 是密码长度
- 空间复杂度：`O(1)`

## 易错点

- `T` 表示测试数据组数，需要处理 `T` 个密码。
- 长度不足 8 时，无论字符类型有多少都是 `Weak`。
- 正好三种类型才是 `Medium`，四种类型是 `Strong`。
- 输入只含 ASCII 可见字符且不含空格，因此可以使用 `cin >> s`。
