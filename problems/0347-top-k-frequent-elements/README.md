# 347. 前 K 个高频元素

难度：中等  
专题：数组 / 哈希表 / 桶排序

## 思路

先用哈希表统计每个数字出现的次数：

```cpp
frequency[num]++;
```

一个数字最多出现 `nums.size()` 次，因此创建 `nums.size() + 1` 个桶。桶的下标表示出现次数，桶中保存具有该出现次数的数字：

```cpp
buckets[count].push_back(num);
```

最后从最高频率向最低频率遍历，取出前 `k` 个数字。

## 为什么优于排序

如果把所有数字按照频率排序，时间复杂度是 `O(m log m)`，其中 `m` 是不同数字的数量。

桶排序不需要比较元素，只需要扫描哈希表和所有桶，因此总时间复杂度是 `O(n)`。

## 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 易错点

- 桶数组大小必须是 `nums.size() + 1`，因为最高频率可能等于 `nums.size()`。
- 应从最高频率向最低频率遍历。
- 结果收集到 `k` 个元素后立即返回。
- `entry.first` 是数字，`entry.second` 是出现次数。
