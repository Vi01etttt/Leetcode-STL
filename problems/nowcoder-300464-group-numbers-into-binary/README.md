# 17. 组数制进二

平台题号：牛客 NC300464  
专题：位运算 / 贪心

## 核心观察

只看某一个二进制位，`a[i]` 和 `x` 的这一位经过操作后会发生以下变化：

| 操作前 `(a[i], x)` | 操作后 `(a[i] or x, a[i] and x)` |
| --- | --- |
| `00` | `00` |
| `01` | `10` |
| `10` | `10` |
| `11` | `11` |

因此，操作不会改变这一位上 `1` 的总数量，只能把 `x` 中的一个 `1` 转移给数组中的一个元素。

对于有效范围内的每一个二进制位：

- 如果所有数组元素在这一位都是 `1`，数组已经不能继续增加，最小的 `x` 应该取 `0`。
- 如果至少一个数组元素在这一位是 `0`，令 `x` 的这一位为 `1`，就能把它转移给一个为 `0` 的数组元素，使数组总和增加这一位的权值。

所有元素按位与的结果 `allAnd` 中，某一位为 `1`，恰好表示所有元素的这一位都是 `1`。所以：

```cpp
minX = (~allAnd) & validMask;
```

`validMask` 用来保证 `x` 的二进制位数不超过数组最大值的二进制位数。

每个被设置到 `x` 中的二进制位都能让数组总和增加相同的权值，因此：

```cpp
maxSum = originalSum + minX;
```

## 复杂度

- 时间复杂度：每组数据 `O(n)`
- 空间复杂度：`O(1)`

## 易错点

- 数组总和最大约为 `500 * (2^30 - 1)`，需要使用 `long long`。
- 最大值为 `0` 时，题目规定二进制位数为 `1`，此时有效掩码是 `1`。
- 按位取反 `~allAnd` 会产生高位的 `1`，必须再和 `validMask` 做按位与。
