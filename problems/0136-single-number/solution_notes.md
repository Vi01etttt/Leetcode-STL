# 0136. Single Number 复盘

## 解法对比

### 哈希表

统计每个数字出现次数，然后找频次为 `1` 的数字。

- 优点：直观，容易写。
- 缺点：额外空间是 `O(n)`。

### 异或

把所有数字异或起来，重复两次的数字会抵消。

- 优点：`O(n)` 时间，`O(1)` 空间。
- 缺点：需要知道异或性质。

## 识别信号

- 只有一个数出现一次。
- 其他数都出现两次。
- 要求 `O(1)` 空间。

这些条件组合起来，强烈暗示用异或。
