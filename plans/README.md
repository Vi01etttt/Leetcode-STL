# 刷题计划

这里记录阶段性计划和复盘。

建议节奏：

- 每天 1-3 道题，重点不是数量，而是复盘质量。
- 新题当天写清楚思路。
- 第 2 天快速回忆并重写关键代码。
- 第 7 天复刷容易忘的题。
- 面试前按专题集中复习。
